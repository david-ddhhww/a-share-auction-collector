结论：字段语义硬门槛通过；全市场吞吐硬门槛待下一交易日 09:26 验证。

## 验证方法

1. 读取 AKShare `stock_zh_a_hist_pre_min_em` 当前底层东方财富 `trends2/get` 原始 JSON。
2. 将 09:15–09:31 的量额逐行检查。
3. 用独立结构化逐笔接口的 09:25:00/09:25:01 最终撮合记录交叉验证价格和成交量；重复逐笔按“价格+成交量”去重。
4. 对四个板块各抽取 5 只，共 20 只。

## 正确映射

| 逻辑字段 | 源字段/源行 | 说明 |
|---|---|---|
| 逻辑竞价时间 | 09:25 | 交易所最终撮合时点 |
| 源时间标签 | 09:26 | 东方财富将最终撮合量额写入此行 |
| 竞价价格 | f53 | AKShare 列名“收盘” |
| 竞价成交量 | f56 | 单位为手；科创板零股可能导致取整 |
| 竞价成交额 | f57 | 单位元，金额唯一真源 |

不能取 09:25 行，因为 20/20 样本量额均为 0；不能取 09:30/09:31 行，因为 09:31 已包含 09:30:xx 连续竞价。
