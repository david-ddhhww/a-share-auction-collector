# 部署说明

推荐目标：Linux 普通用户目录 `/home/ubuntu/a-share-auction-collector`，Python 3.11+，SQLite，systemd timer。

## 安装

```bash
cd /home/ubuntu/a-share-auction-collector
python3 -m venv .venv
.venv/bin/pip install -e .
```

复制 `deploy/systemd/a-share-auction-collector.service` 和 `.timer` 到用户级 systemd 目录：

```bash
mkdir -p ~/.config/systemd/user
cp deploy/systemd/a-share-auction-collector.* ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now a-share-auction-collector.timer
systemctl --user list-timers a-share-auction-collector.timer
```

如果服务器未启用用户 lingering，重启/退出登录后用户定时器可能不运行，需要管理员执行：

```bash
sudo loginctl enable-linger ubuntu
```

也可由管理员把单元复制到 `/etc/systemd/system/` 并改为系统级服务。

## 验证

```bash
systemd-analyze calendar 'Mon..Fri *-*-* 09:26:00 Asia/Shanghai'
systemctl --user start a-share-auction-collector.service
journalctl --user -u a-share-auction-collector.service -n 100 --no-pager
```

注意：手动启动若不在 09:26 实盘窗口，默认会安全阻断。盘后只能显式使用逐股补采；批量 f6 在盘后代表全天累计成交额，绝不能当集合竞价额。
